Text contrast rule. Teachers may be reading dense numerics for hours; some are older. Treat gray-400 as a decoration-only token — dividers, dashed borders, status dots, icon outlines. Never use it for text. Default secondary text uses gray-500 (5.5:1 on white, WCAG AA), and small monospace metadata — roll numbers, denominators, table cell labels — uses gray-600 (9:1, WCAG AAA) since small thin type is hardest to read.
